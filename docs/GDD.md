# 삼국 패권 — 게임 디자인 문서 (GDD)

## 1. 게임 개요

### 제목
삼국 패권

### 장르
턴 기반 지역 점령 전략 게임

### 플랫폼/엔진
- PC
- Love2D (11.5)
- Lua

### 핵심 콘셉트
플레이어는 삼국지 시대의 군주 중 하나를 선택해 중국 전역의 거점을 운영하고,
장수를 등용·육성하며, 병력과 군량을 관리해 천하 통일을 목표로 한다.

### 설계 방향
- 시나리오와 군주를 선택해 시작한다.
- 지도 위 거점을 클릭해 정보를 확인하고 명령을 수행한다.
- 매 턴 세금, 군량, 인구, AI 행동을 처리한다.
- 전쟁·이동·수송·내정·훈련·징병·장수 관리가 하나의 순환 구조로 연결된다.

## 2. 목표 경험
플레이어는 제한된 자원 안에서 어떤 도시를 키우고, 어떤 장수를 전장에 보내며,
언제 공격할지 판단한다. 강한 장수 하나만으로는 부족하고, 군량 수송·병력 훈련·
충성도 관리·내정 투자까지 함께 고려하는 전략 경험을 제공한다.

## 3. 게임 흐름
1. 시나리오 선택
2. 플레이할 군주 선택
3. 시작 거점과 장수 확인
4. 내정/징병/훈련/건설/수송/이동/전쟁 명령 수행
5. 턴 종료
6. 이동·수송 도착 처리
7. 세금·군량·인구 성장 처리
8. AI 세력 행동 처리
9. 반복 진행

## 4. 시나리오
3개 시나리오를 제공한다.

| 시나리오 ID | 연도 | 설명 |
| --- | ---: | --- |
| `yellow_turban` | 184 | 황건적의 난 시기 |
| `warlords` | 194 | 군웅할거 시기 |
| `three_kingdoms` | 221 | 삼국 정립 시기 |

각 시나리오 데이터:
- 세력(faction) 목록: 세력 id, 표시 이름, 고유 색(GDD 6장)
- 지역별 초기 소유 세력(ownership: 지역 id → 세력 id). 미기재 지역은 중립
- 선택 가능한 군주 목록 / 군주별 수도·거점 (추후)
- 장수 초기 배치 / 능력치·장비 (추후)

### 시나리오별 세력(요약 고증)
- `yellow_turban` (184): 황건적 / 동탁 / 마등 / 유언 / 하진 / 정원 / 공손찬 / 손견
  (게임적 허용 — 한 관군 제외, 군웅 8세력 전 지역 분할)
- `warlords` (194): 원소 / 공손찬 / 조조 / 도겸·유비 / 이각·곽사 / 마등·한수 /
  원술 / 유표 / 손책 / 유장 / 장로 (11세력, 전 지역 분할)
- `three_kingdoms` (221): 위(조비) / 촉(유비) / 오(손권), 변경 일부 중립

> 시작 화면에서 시나리오를 선택해 진입한다. 30지역 지도는 공유하고,
> 시나리오는 세력 구성과 지역 소유만 바꾼다(CLAUDE 지도/지역 규칙).

## 6. 세력과 소유권

### 소유권 타입
- 플레이어 세력 / AI 세력 / 중립 지역

### 소유↔배치 정합성 (배치 우선)
- **세력 소유 지역에는 active 장수가 최소 1명 배치된다.** (장수 배치가 소유의 진실원본)
- **active 장수가 0명이 된 소유 지역은 중립으로 전환된다.** (소유는 있는데 지킬 장수가 없으면 무주공산)
- 이 규칙은 **시작 배치**(시나리오 로드 직후 정규화)와 **런타임**(이동/전투로 active 0명이 되는 순간)에
  **동일하게** 적용한다. 중립 전환 시 그 지역 태수도 해제된다.

### 색상 규칙
- 세력색은 **시나리오 데이터(factions[*].color)에서 세력별 고유색**으로 정의한다.
  세력 수가 시나리오마다 다르므로(184=4, 194=11, 221=3) 고정 3색이 아니다.
- 221(삼국): 위=파랑, 촉=초록, 오=빨강 (관례 유지).
- 빈 땅(중립, ownership 미기재): 회색.
- 플레이어 소유: 내부 세력색 유지 + 흰색 테두리(추후 군주 선택 후).
- 선택 지역/명령 대상: 별도 테두리 강조(노랑).

### 외교/적대치
- **적대치**는 세력 쌍(A→B) 간 적대 수준 수치다. 0~100, 높을수록 적대적.
- 지역 고유 필드가 **아니다** → 세력 관계 데이터 `hostility[A][B]` (2중 테이블)로 저장.
  비대칭 허용(A→B 와 B→A 가 다를 수 있음). 자기 자신 `hostility[A][A]` 는 정의하지 않음.
- 시나리오 데이터에 연의 기반 **기본 적대치**를 둔다. 직접 수치를 나열하지 않고
  **단계(동맹/우호/중립/적대)** 로 정의하고, 단계→수치 변환은 코드 상수표(`config.hostility`)가 맡는다.
  - 단계 기준값: 동맹=0, 우호=20, 중립=50, 적대=85.
  - 미기재 세력 쌍은 중립(50)으로 본다.
- **지역 정보 패널의 적대치** = 그 지역 소유 세력 → 플레이어 세력 적대치 값.
  - 플레이어 본인 소유 지역 = `-`. 중립(미소유) 지역 = `-`. (적 세력 소유일 때만 수치)
- 동적 로직(추후 — GDD 13 전투 / 16 AI 연동 시 구현):
  - 적대치 높을수록 그 세력의 플레이어 공격 확률 증가.
  - 플레이어가 먼저 공격한 세력은 적대치 최대.
  - 공격받은 세력과 우호 관계인 세력들의 적대치도 연쇄 상승.
  - ※ 위 동적 로직은 현재 범위 아님. 데이터 + 조회 + 표시만 구현.

## 7. 장수 시스템


### 설계 의도

장수는 본 게임의 핵심 자원이다.

플레이어는 단순히 지역을 점령하는 것이 아니라,
인재 탐색, 등용, 육성, 장비 관리 등을 통해
유능한 장수를 확보하고 활용해야 한다.

지역 점령과 장수 확보는 모두 천하 통일을 위한
동등하게 중요한 전략 요소로 취급한다.

### 능력치
체력, 무력, 지력, 정치, 충성도, 보유 병력, 장비, 소속 세력, 위치 지역,
이동 중 여부, 포로/처형 상태. (수장은 충성도 대신 `-`)

### 병력 한도
```text
장수 병력 한도 = 무력 * 5
```

### 행동 제한
장수는 같은 턴에 주요 행동을 반복할 수 없다. 이동·수송·훈련·내정은
장수의 행동 완료 상태를 사용한다.

### 장수 규모

- 게임 전체 장수 풀은 약 180~200명을 목표로 한다(상한 ~200 쪽으로 채운다).
- 장수는 시나리오별로 모두 동일하게 사용되지 않는다.
- 각 시나리오는 시대적 배경에 따라 일부 장수만 초기 배치한다.
- 지역 수는 30개지만, 장수는 지역당 평균 6명 수준을 목표로 한다.
  - 단, "평균 6명"은 전체 **밀도 목표**일 뿐 per-지역 강제가 아니다.
    강제 불변식은 6장 "소유↔배치 정합성"의 **소유 지역 active ≥1**(미달 시 중립 전환)이다.

### 장수 상태

장수는 다음 상태 중 하나를 가진다.

| 상태 | 설명 |
|--------|--------|
| active | 세력에 소속된 장수 |
| free | 재야 장수 |
| unrevealed | 아직 등장하지 않은 장수 |
| captured | 포로 |
| dead | 사망 |

시나리오 시작 시 모든 장수가 세력에 소속될 필요는 없다.

일부 장수는 재야 상태로 지역에 숨어 있으며,
플레이어 또는 AI가 탐색을 통해 발견하고 등용할 수 있다.

일부 장수는 해당 시대 이전 인물이므로
아직 등장하지 않은 상태(unrevealed)로 시작한다.


## 8. 장비 시스템
- 장비는 능력치 보너스(체력/무력/지력/정치)를 준다.
- 한 장수에게만 장착된다.
- 시작 장착 장비는 해당 세력 군주에게 귀속.
- 군주 보유 장비는 세력 장수에게 선물 가능 → 보너스 이전 + 충성 상승.
- 포로 등용 시 장비 동반, 처형 시 장비는 군주 귀속.

## 9. 자원 시스템

### 종류
금, 군량, 인구, 병력

### 금 — 지역별 보유 단일 진실원본
- 금은 **전적으로 "지역별 보유"가 진실원본**이다. 세력 단일 금고나 "군주 소재/위치 금" 같은 개념은 **두지 않는다**.
- 모든 금 소모·획득(세금·내정 투자·징병·선물 등)은 **그 행동이 일어나는 지역의 금**을 쓰고/그 지역 금에 가산한다.
- 선물도 대상 장수가 아니라 **명령을 수행하는 지역(=장수 명령을 연 선택 지역)의 지역 금**에서 차감한다.
  군주가 어디 있는지로 금 풀을 특수취급하지 않는다.

### 금 수입
매 턴 소유 지역에서 세금 자동 징수. 세금은 상업·토지 가치·민충성·
장수 정치력에 영향. 징수액은 그 지역 금에 가산한다(금 보유는 지역별).

### 군량
- 특정 월(7월) 수확. 수확량은 토지 가치·치수·민충성·정치력 기반. 그 지역 군량에 가산.
- 군량 가격은 월별 기본가 + 무작위 변동. 매입/판매 가능.

## 10. 내정 시스템
소유 지역에서 자원을 투자해 내정 수치를 올린다.

### 투자 항목
치수 투자, 민충성 투자, 상업 투자, 토지 투자

### 규칙
- 지역당 같은 항목은 한 턴 1회.
- 수행 장수 필요. 정치 높을수록 효율 ↑.
- 투자 금액은 슬라이더 선택.
- 수행 후 해당 버튼은 빨간색 비활성 표시.

### 투자 비용 자원
- **민충성 투자만 금이 아니라 군량을 소모**한다(민심 안정에 곡식을 푼다는 개념). 그 지역 군량에서 차감하고, 군량 부족 시 투자 불가.
- 나머지(치수·상업·토지) 투자는 금을 소모한다(그 지역 금에서 차감, 9장).

### 인재 탐색

소유 지역에서 장수를 사용해 인재 탐색을 수행할 수 있다.

- 수행 장수 필요
- 지역당 턴 1회
- 정치 능력이 높을수록 성공 확률 증가
- 성공 시 해당 지역의 재야 장수를 발견
- 발견된 장수는 등용 시도 가능

인재 탐색은 장수 확보의 주요 수단 중 하나다.

## 11. 징병/훈련 시스템

### 징병
- 금 소모(기본 70).
- 인구 감소, 민충성 하락.
- 장수 병력 수용 한도 초과 불가.
- 새 병력 훈련도 0, 기존+신규 가중평균으로 지역 훈련도 재계산.

### 훈련
- 지역 병력 훈련도 0~100. 전투력에 반영.
- 수행 장수 무력 높을수록 상승량 ↑ (무력 100급 ≈ 10회로 100).
- 지역당 한 턴 1회.

## 12. 이동/수송 시스템

### 부대 명령
장수·병력·군량을 선택한 뒤 목적지를 클릭해 확정.

### 이동
- 플레이어 소유 지역 이동(거리 무제한).
- 인접 중립 지역은 이동/점령 대상.
- 다음 턴 도착. 도착 시 병력 합류.
- 출발지에 장수 0명이면 남은 병력 0 처리.
- 경로는 지도 위 점선 화살표로 표시.

### 수송
- 장수 1명이 군량을 들고 소유 지역으로 이동. 다음 턴 도착.
- 수송 경로는 이동과 다른 색 점선 화살표.

## 13. 전투 시스템

### 전쟁 진입
- 부대 명령에서 전쟁 모드 선택.
- 공격 대상 = 인접 적 소유 지역. 선택 시 전투 화면 전환.
- 빈 땅은 인접에서 무혈 입성.

### 전투 처리(목표)
- 책략전 스타일 그리드 전투.
- 데려간 장수 수만큼 전투 유닛 생성.
- 유닛 공격력/방어력 = 장수 무력 + 투입 병력 + 출발지 훈련도 기반.
- 플레이어가 전투 턴마다 유닛을 직접 이동·공격(자동 결과 아님).
- 전투도 이동처럼 선언 후 점선 화살표 → 다음 턴 처리.
- 승리 시 소유권 이전, 패배 시 공격 병력 손실.

## 14. 포로/등용/처형
- 점령 시 적 장수 50% 확률 포획. 실패 시 같은 세력 다른 지역 도주, 도주지 없으면 전원 포획.
- 포로 팝업: 등용 / 처형.
- 등용 확률은 충성도 낮을수록 높음. 성공 시 플레이어 장수 편입.
- 장비 보유 포로: 등용 시 장비 동반, 처형 시 장비는 군주 귀속.

## 15. 선물 시스템
- 금 선물: 장수당 턴 1회, 0~10금, 1금 = 충성 +5.
- 장비 선물: 장수당 턴 1회, 군주 보유 장비 중 선택, 보너스 이전 + 충성 상승.

## 16. AI 시스템
AI 세력은 턴 종료 후 각 지역을 순회하며 행동.

### 우선순위
1. 공격 가능한 유리한 목표 탐색 → 2. 공격 → 3. 병력 부족 시 징병
→ 4. 훈련도 낮으면 훈련 → 5. 내정 수치 낮으면 개발

### 공격 판단
- 병력 일정 이상 지역만 공격 후보.
- 중립 지역 더 적극, 플레이어 지역 추가 가중치.
- 병력 차 충분히 유리할 때 공격.

## 17. UI/UX

### 기본 화면
- 좌측/중앙: 월드맵
- 우측: 선택 지역 정보 패널
- 상단 좌측: 날짜
- 우측 하단: 명령 버튼

### 주요 팝업
시나리오 선택, 군주 선택, 부대 명령, 전투 화면, 훈련 장수 선택,
내정 장수/투자금 선택, 수송 장수/군량 선택, 장수 목록, 금 선물,
장비 선물, 군량 매입/판매, 포로 처리

### 입력
- 좌클릭: 지역/버튼 선택
- 드래그: 카메라 이동
- 휠: 확대/축소
- `Esc`: 팝업 닫기

## 18. 승리/패배 조건
- 승리: 모든 지역 플레이어 소유 시 천하 통일.
- 패배: 플레이어 소유 지역 0개, 또는 군주 사망/처형(후계 없음).

## 19. 모듈 설계
| 파일 | 역할 |
| --- | --- |
| `project/src/main.lua` | Love2D 생명주기, 렌더링, 입력, 팝업 UI |
| `project/src/game_state.lua` | 게임 상태, 규칙(장수·경제·턴·외교), AI |
| `project/src/develop.lua` | 내정 규칙(투자/인재 탐색·등용) — game_state 800줄 초과로 분리(10·14장) |
| `project/src/game_data.lua` | 시나리오, 지역, 장수, 장비 데이터 |
| `project/src/region.lua` | 지역 조회, 인접 판정 |
| `project/src/ui.lua` | 버튼 렌더링과 클릭 판정 |
| `project/src/popup.lua` | 장수 목록/상세·선물·지역정보 모달 팝업(17장) |
| `project/src/dev_popup.lua` | 내정(투자/탐색·등용) 모달 팝업(10·17장) |
| `project/src/camera.lua` | 카메라 좌표 변환, 이동, 줌 |
| `project/src/config.lua` | 창·색·계수 상수 |
| `project/src/conf.lua` | Love2D 설정 진입점 |

### 설계 원칙
- 데이터는 `game_data.lua`에 모은다.
- 규칙은 `game_state.lua`에 둔다.
- Love2D 입력/그리기는 `main.lua`에서 처리한다.
- 지역 유틸은 `region.lua`, UI 버튼은 `ui.lua`로 분리한다.
- 모듈은 작게 유지하고 암묵적 전역을 피한다.

## 20. 개발 로드맵
- 지도/카메라 → 시나리오/선택 → 내정/세금/턴 → 훈련/징병/이동
  → 전투/포획/장수관리 → 그리드 전투 → 다중 장수/세이브·로드 → 테스트/문서.
