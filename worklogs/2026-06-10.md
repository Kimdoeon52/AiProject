## 설계 결정

- **내정 진입 UI = 허브 팝업**(사용자 확정). 우측 패널엔 "내정" 버튼 1개 → 모달 팝업에 5개 명령.
  패널 혼잡 회피 + 기존 popup 모달 패턴 일치.
- **투자금 = 클릭형 슬라이더 트랙 + −/+/최대**(사용자 확정). 드래그 배선 불필요(main 변경 최소).
- **투자 1회 제한 = 2중**: 지역당 항목별 `region.devDone[item]` + 수행 장수 `actionDone`(GDD 10장).
- **탐색 1회 = `region.searchDone`** + 수행 장수 행동 소진. 성공 시 그 지역 미발견 free 1명 `discovered=true`.
- **등용**: 발견된 free 대상, 수행 장수 행동 소진(재시도 스팸 방지). 성공 시 active·플레이어 세력 편입.
  탐색은 "소유 지역에서"만 → active 1명 추가가 정합성 자동 만족(별도 소유 갱신 불필요). **포로 로직과 분리.**
- **확률·랜덤은 develop 안**에서 주입 `rng()`(→[0,1)) 사용 → 시드 고정 테스트 가능(love 비의존).
  main 은 `love.math.random` 주입.
- **턴 1회 플래그 리셋**은 `advanceTurn` 6-b 에서 `resetRegionActions`(선물·행동완료와 같은 지점).
