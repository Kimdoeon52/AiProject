### 장비 (GDD 8장)
- 데이터: `items`(id/name/hp/force/intelligence/politics). 보너스 필드 키가 장수 능력치 키와 달라
  `game_state` 에서 매핑(force→무력, intelligence→지력, politics→정치, hp→체력). 음수=패널티 허용(예: 대부 지력 -2).
- 시작 장비는 각 세력 **군주에게 귀속**(미장착) → 군주 장비고(선물 대상). `applyInitialEquipment` 가 구성.
- 규칙: 1장수 1장착(`officer.equip`). 유효 능력치 = 기본 + 장비 보너스(`effectiveStat`).
  스탯별 보너스 판별(`statBonus`/`hasStatBonus`) → 표시 색 분기에 사용.
- 장비 선물: `canGiftEquip`(수장 제외/턴1회/빈 장착칸) → `applyGiftEquip`(장비고에서 제거 + 장착 + 충성 상승 + 턴 플래그).
- 포로 동반/처형 귀속(GDD 8·14장)은 범위 밖 → TODO 주석만.

### 태수 (GDD 5장)
- `assignGovernor(officers, regionId, rng)`: ① active 후보 → ② 수장 있으면 고정 → ③ 없으면 최고 충성 →
  ④ 동률이면 그 그룹 랜덤(주입 rng) → ⑤ 후보 0명 nil.
- `assignGovernors`(초기 1회 전 지역), `governorRegionOf`(역조회), `canSetGovernor`(수동: 같은 지역 active).
- 수동 지정/해제는 상세의 "태수 지정/해제" 버튼(플레이어 세력 active 장수만). 이동 시 해제는 이동 시스템 도입 후(주석).

### UI (popup.lua)
- 상세 능력치는 **유효치(기본+장비)** 로 표기, 보너스(+) 스탯은 **연두**, 패널티(−)는 빨강, 없으면 기본색.
  draw 는 `statBonus` "조회"만 하고 색만 선택(계산은 game_state) — 3계층 유지.
- "태수: <지역>" 역조회 표시, "보유 장비: 이름 (보너스)" 또는 "없음".
- 액션 버튼: [태수 지정/해제] + [금 선물][장비 선물]. 장비 선물은 군주 장비고 목록 서브팝업에서 선택→이전.
- ESC/X 는 서브팝업(금/장비) → 상세 → 목록 순으로 한 겹씩.
