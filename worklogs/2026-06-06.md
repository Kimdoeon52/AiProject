## 지시 요약
- `project/src/` 아래 코드 배치.
- `conf.lua`/`config.lua`: Full HD(1920x1080) 창 설정.
- `camera.lua`: 카메라 이동/줌, 스크린↔월드 좌표 변환.
- `region.lua`: 지역 조회, 인접 판정, 클릭(점 포함) 판정.
- `main.lua`: Love2D 생명주기(load/update/draw/mousepressed/mousemoved/wheelmoved).
- 세력색: 위=파랑, 촉=초록, 오=빨강, 중립=회색. 한글 폰트 malgun.ttf.
- 마무리: 루트 `run.bat`, 이 워크로그, git 커밋.

## 구현 내용
계층 분리(CLAUDE.md) 준수해 6개 모듈 작성:

| 파일 | 계층 | 책임 |
| --- | --- | --- |
| `config.lua` | 상수 | 창·색상·줌·노드 크기. 매직넘버 집중 |
| `conf.lua` | 진입 | `love.conf` — config 읽어 1920x1080 창 |
| `game_data.lua` | 데이터 | 거점 40개(id/name/x/y/owner/neighbors) |
| `camera.lua` | 유틸(순수) | screenToWorld/worldToScreen/move/zoomAt |
| `region.lua` | 유틸(순수) | byId/areAdjacent/connections/hitTest |
| `main.lua` | 표현·입력 | LÖVE 콜백, 렌더, 드래그/줌/클릭 |

- 지역 40개: 실제 삼국지 거점을 대략 중국 지리 배치(북=위, 서=촉, 동남=오,
  형주·남방=중립)로 분산. owner 분배는 Day1 색상 시연용 초기값.
- `camera.lua`/`region.lua`는 `love.*` 비의존 순수 Lua → 단위 테스트 가능.
- 화면 transform(translate/scale)은 main.draw 에서만 수행 → camera 순수성 유지.
- `project/tests/test_pure.lua` 추가: 좌표 변환·인접·hitTest·neighbors 양방향 검증.

## 시도·실패 / 원인 / 수정
- **표준 Lua 인터프리터 부재.** `lua`/`luajit` 미설치라 순수 테스트를 직접 실행 불가.
  - 원인: 환경에 standalone Lua 없음. 번들된 건 `lovec.exe`(lua51 내장)뿐.
  - 수정: 창 숨김 헤드리스 LÖVE 하네스(임시 dir)로 `test_pure.lua` 를 `dofile` 해
    lovec 내장 Lua VM 으로 실행 → **16 통과 / 0 실패** 확인 후 임시 dir 삭제.
- **GateGuard 훅(fact-force).** 각 파일 쓰기 전 사실 확인 요구로 매 Write 1회 차단.
  - 원인: 세션 보호 훅(`pre:edit-write:gateguard-fact-force`)이 신규 파일마다 발동.
  - 수정: 매 파일마다 호출자/중복여부/데이터형식/지시문 4사실 제시 후 재시도. 정상 진행.
