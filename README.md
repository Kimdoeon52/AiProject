# 삼국 패권 — README

턴 기반 지역 점령 전략 게임. LÖVE2D 11.5 / Lua.

---

## 요구사항

| 항목 | 버전 | 용도 |
|---|---|---|
| LÖVE2D | 11.5 | 게임 실행 (`lovec.exe`) |
| Lua 인터프리터 | 5.4 | 단위 테스트 실행 (`lua`) |

`love-11.5-win64\` 폴더가 프로젝트 루트에 **동봉**되어 있다.  
Lua 5.4는 별도 설치 필요 — [lua.org/download](https://lua.org/download.html) 또는 `winget install DEVCOM.Lua`.

---

## 빠른 시작 (3단계)

```bat
:: 1. 클론 또는 압축 해제 후 프로젝트 루트로 이동
:: 2. 게임 실행
run.bat
:: 3. 화면에서 시나리오 선택 → 군주 선택 → 지도 진입
```

직접 실행도 동일:

```bat
love-11.5-win64\lovec.exe project\src
```

## 조작법

| 입력 | 동작 |
|---|---|
| 좌클릭 | 지역 선택 / 버튼 클릭 |
| 드래그 (좌버튼 누른 채 이동) | 카메라 이동 |
| 마우스 휠 | 지도 확대/축소 |
| `Esc` | 팝업 닫기 / 선택 취소 |

**부대 명령 팝업** (지역 선택 후 "부대 명령" 버튼):

- 이동: 출발 지역 장수 선택 → 목적지 지역 클릭
- 수송: 군량 수량 입력 → 목적지 클릭
- 전투 선언: 목적지가 적 소유일 때 활성화 → 출진할 장수 체크박스로 선택

**전투 화면** (그리드):

- 좌클릭 유닛 → 이동 가능 칸 표시 → 목적지 클릭
- 이동 후 사거리 내 적 클릭 → 공격
- "자동" 버튼: 남은 전투 자동 진행

## 단위 테스트 (순수 Lua, love 비의존)

```bat
lua project\tests\test_pure.lua
```

**실행 예시 출력:**

```
테스트 결과: 334 통과 / 0 실패
```

실패 케이스가 있으면 `[FAIL] <설명>` 한 줄씩 출력.  
종료 코드 0 = 전원 통과, 1 = 실패 존재.

**검증 범위:**

| 모듈 | 검증 내용 |
|---|---|
| `camera` | 월드↔스크린 왕복 변환, 이동, 줌 커서 고정, 경계 클램프 |
| `hex` | axial↔픽셀 왕복, 6방향 이웃, 꼭짓점 12값 |
| `region` | byId 조회, 헥스 인접 판정, cellAt 클릭 명중 |
| `game_data` | 지역 30개, 좌표 중복 없음, GDD 지역명 일치, 금지 지명(백제 등) 없음, 시나리오 3개 |
| `game_state` | 장수 풀·상태 5종, 태수 자동선정, 징병·훈련 공식, 세금·수확 공식, 금 지역 단일원본, 선물 시스템, 군량 월별가격, 적대치, 출진 장수 선택(atkList) |
| `develop` | 투자 4종 턴 제한·비용, 인재 탐색·등용 확률 |
| `movement` | canMove·canTransport 규칙, 명령 발행, 빈집 자동 중립 강등 |
| `battle` | canDeclareWar, 유닛 생성·스탯 공식, 데미지 계산, 승패 판정, 결과 반영, AI N-1 출진 |
| `captive` | 포획 판정, 도주, 등용·처형 |
| `ai` | AI.run — 징병/훈련/내정/공격 4단계, 자동 전투 결과 |
| `victory` | 30지역 통일 승리, 소유 0 패배, 군주 사망 패배 |

## 수동 검증 체크리스트

- [ ] 시나리오 선택 → 군주 선택 → 지도 진입
- [ ] 내정(치수/민충성/상업/토지), 세금 수령, 수확(7월)
- [ ] 징병 → 훈련 → 장수 이동/수송
- [ ] 전투 선언 → 장수 체크박스 선택 → 그리드 전술 전투 → 점령
- [ ] 점령 후 포로 팝업 → 등용/처형
- [ ] AI 세력 턴마다 징병/훈련/개발/공격
- [ ] 전 지역 점령 → 승리 화면 → "메인으로" 복귀
- [ ] 소유 지역 0 or 군주 사망 → 패배 화면 → 복귀
